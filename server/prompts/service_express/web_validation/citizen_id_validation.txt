Validate citizen ID requirements and return JSON array of validation results.

Validation Rules:

"Individual or Corporate" - Analyze "Customer Name": if clearly person's name (given name + surname, no business identifiers) = "Individual"; if contains business terms like "Co.", "Ltd.", "Inc.", "Corporation" = "Corporate"; if uncertain = "—"

"แนบหนังสือรับรองบริษัท" - Check if PDF includes corporate certificate document or "หนังสือรับรองความเป็นนิติบุคคล": present = "Yes", not present = "No"

"Citizen ID Number" - Must be exactly 13 digits (ignore whitespace, dash, separators, count only numbers). Valid if matches /^\d{13}$/. If "Individual or Corporate" is "Corporate": mark valid with reason "Corporate customer, no need citizen ID"

"Citizen ID expiration date" - Valid if expiration date is at least 6 months in future from today. If "Individual or Corporate" is "Corporate": mark valid with reason "Corporate customer, no need citizen ID"

"มีตราประทับบนหนังสือรับรองบริษัทหรือไม่" - If customer is "Corporate": verify certificate has official company stamp (present = "Yes"/valid, absent = "No"/invalid). If "Individual": return "—" (valid by default)

"Name on Citizen ID card" - If "Individual or Corporate" is "Corporate": mark valid with reason "Corporate customer, no need citizen ID". If "Individual": verify ID card name matches "Customer Name" exactly (ignore initials like นาย นางสาว น.ส., check actual name). Match = "Yes"/valid, no match = "No"/invalid

"Address on Citizen ID card" - Valid if non-null, invalid if null or empty

Return format:
[
  {

    "value": "Extracted value (or null)",

    "reason": "Explanation"
  }
