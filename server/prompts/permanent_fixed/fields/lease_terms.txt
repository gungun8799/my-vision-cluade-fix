Extract lease terms for PERMANENT FIXED contracts and return as a complete JSON object with ALL required fields listed below.

**INTELLIGENT YEAR ALLOCATION LOGIC:**
When extracting Year-by-Year details, MUST intelligently calculate year boundaries:

FOR PDF SOURCES:
- Extract actual year-by-year terms as specified in contract sections
- Each year should have exactly 12 months (1 year) duration

FOR WEB SOURCES (Simplicity system):
- Use "Proposed lease commencement date" and "Proposed lease expiry date" to calculate total duration
- Divide total lease duration into equal 1-year periods
- Calculate year boundaries intelligently:
  * Year 1: Start = Proposed commencement date, End = Start date + 11 months + 30 days
  * Year 2: Start = Year 1 End date + 1 day, End = Start date + 11 months + 30 days  
  * Year 3: Start = Year 2 End date + 1 day, End = Proposed expiry date (or calculated)

**DYNAMIC YEAR INCLUSION:**
- Only include years that actually exist in the contract duration
- If lease is 2 years total, only show Year 1 and Year 2
- If lease is 1 year total, only show Year 1
- Do NOT include Year 3 unless contract actually spans 3+ years

"Monthly charge" - Output "Yes" or "No"

**AMOUNT ALLOCATION RULES:**
FOR PDF SOURCES: Extract year-specific amounts if they exist
FOR WEB SOURCES: Use same base amounts for all years unless explicitly different

**AMOUNT EXTRACTION PRIORITY (Web):**
1. Look for "Monthly Rent" or "Rental Amount" in main lease details (NOT per-square-meter rates)
2. Look for "Service Charge" or "Service Fee" amounts (NOT per-square-meter rates) 
3. If you find per-square-meter rates (e.g., "101.4024 per sqm"), multiply by total area to get monthly amount
4. If only total amounts found, divide by number of years
5. Ensure amounts are in Thai Baht (THB) - typical range: 5,000-50,000 THB/month
6. **WARNING:** If extracted amount seems too small (under 1,000 THB), it might be per-sqm rate - recalculate
