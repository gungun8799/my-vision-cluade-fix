Compare lease property tax information between PDF and Web sources. Return JSON array of comparison results.

Compare this field:

"Lease property tax" - Apply these validation rules:
1. Web value "PTS-PT Standard" (ignore spaces) → PDF must be "10.00" to be valid
2. Web value "PT Mall" (ignore spaces) → PDF must be "12.5" to be valid  
3. Web value null/missing → PDF must be "0" to be valid

Validation Logic:
- For tax rates, exact matching is required based on web value type
- Missing values in either source = false match

NOTE: Deposit amounts are handled in the lease_terms category, not here.

Return format:
[
  {
    "field": "Lease property tax", 
    "pdf": "PDF value",
    "web": "Web value",
    "match": true or false,
    "reason": "Tax rule applied: [explanation]"
  }
]
